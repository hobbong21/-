# ⚖️ [03_암기요약표] 02. 헷갈리는 핵심 개념 1:1 비교 정리표

시험 문제 보기에서 항상 매력적인 오답으로 출제되는 헷갈리는 개념들을 1:1로 명쾌하게 비교 정리했습니다.

---

## 1. 수목의 빛 요구도 비교: 양수 vs 음수

| 구분 | 양수 (햇빛 마니아) ☀️ | 음수 (그늘 버팀목) 🌲 |
| :--- | :--- | :--- |
| **광포화점 / 광보상점** | 높음 (빛이 아주 강해야 최대 광합성) | 낮음 (적은 빛으로도 광합성 가능) |
| **어릴 때 특성** | 어릴 때 햇빛 못 받으면 바로 고사 | 어릴 때 어미나무 그늘 밑에서 잘 견딤 |
| **잎의 형태** | 잎이 두껍고 좁으며 책상조직 발달 | 잎이 얇고 넓으며 엽록소 함량 높음 |
| **대표 수종** | **극양수:** 자작나무, 일본잎갈나무(낙엽송), 오시리나무<br>**양수:** 소나무, 상수리나무, 포플러 | **극음수:** 주목, 회송, 나도밤나무<br>**음수:** 잣나무, 전나무, 편백, 삼나무 |

## 2. 숲을 베고 다시 만드는 방식: 갱신 작업종 비교

| 작업종 | 베는 방법 (수확) | 새로운 숲 형성 (갱신) | 장단점 및 특징 |
| :--- | :--- | :--- | :--- |
| **개벌작업 (모두베기)** | 구역 내 나무를 **한꺼번에 전량 벌채** | 인공적으로 묘목을 심거나 씨앗 파종 | 기계화 용이, 비용 저렴 / 토양침식 위험 높음, 경관 훼손 |
| **택벌작업 (골라베기)** | 다 자란 나무나 불량목만 **골라서 벌채** | 자연적으로 떨어진 씨앗에서 어린나무 자람 | 경관 유지, 생태계 보전 우수 / 수확 작업 어렵고 기술 필요 |
| **산벌작업 (점진베기)** | 3단계(예비벌➔하종벌➔후벌)로 나누어 베기 | 어미나무 그늘 밑에서 점진적으로 갱신 | 숲이 항상 보호됨 / 작업 기간이 길고 까다로움 |
| **모수작업 (엄마나무남기기)** | 90% 이상 베고 우량 모수 15~30본 남김 | 남겨둔 엄마나무에서 씨앗이 날려 갱신 | 씨앗 살포 비용 절감 / 모수가 태풍에 쓰러질 위험 있음 |

## 3. 나무 숲의 형태: 교림 vs 왜림 vs 중림

| 구분 | 교림 (喬林, High forest) | 왜림 (矮林, Coppice) | 중림 (中林, Compound forest) |
| :--- | :--- | :--- | :--- |
| **번식 기원** | **종자 (씨앗)** | **맹아 (그루터기 싹)** | **씨앗 + 그루터기 싹 혼합** |
| **나무 크기** | 크고 곧은 아름드리나무 | 키가 작고 여러 갈래 줄기 | 상층은 큰 나무, 하층은 작은 숲 |
| **벌기령 (수명)** | 40 ~ 80년 이상 (장기) | 10 ~ 20년 (단기) | 복층 구조로 번갈아 수확 |
| **생산 목적** | 고급 건축재, 가구재, 원목 | 땔감(장작), 숯, 표고버섯 자목 | 목재와 땔감을 동시 생산 |

---

## 4. 나무 질병의 3대 병원체 비교

| 병원체 종류 | 주요 특징 | 치료 및 약제 | 대표 질병 |
| :--- | :--- | :--- | :--- |
| **진균 (곰팡이)** | 산림 수병의 약 80% 차지. 포자로 번식 | **살균제** (보르도액, 다이센 등) | 잣나무 털녹병, 모잘록병, 그을음병 |
| **세균 (박테리아)** | 세포벽 있음. 비바람이나 전정 가위로 전파 | **항생제** (스트렙토마이신 등) | 뿌리혹병(근두암종병), 불마름병 |
| **파이토플라스마** | 세포벽 없음. 매미충 등 곤충이 매개 | **테트라사이클린계** 항생제 주사 | 대추나무 빗자루병, 오동나무 빗자루병 |

## 5. 산림 자산 평가 3대 기법 비교

| 평가 방식 | 주 대상 (나무 나이) | 계산 핵심 논리 |
| :--- | :--- | :--- |
| **원가법 (비용가법)** | **유령림 (1~20년생 어린나무)** | "지금까지 이 나무를 키우는 데 **들어간 총비용(종자+비료+인건비+복리이자)**" |
| **수익환원법 (기대가치법)** | **중령림 (20~40년생)** | "앞으로 다 자랐을 때 벌어들일 **미래 예상 수익을 현재 가치로 땡겨온 금액**" |
| **시장가역산법 (매매가법)** | **벌기 도달림 (40년 이상 다 자란 나무)** | "지금 당장 베어서 **시장에 내다 팔 가격에서 벌채·운송비를 뺀 순수익**" |
