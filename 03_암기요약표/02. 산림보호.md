# 산림보호 암기 요약표

> 기준: 2026 학습모듈 「산림보호」(V07.26). ★ = 고빈도 · 🆕 = 2026.8.30 개정 반영 부분

## 1. 기상 피해

| 피해 | 핵심 |
|---|---|
| 볕데기(피소) | 수피가 평활한 수종(**오동나무·호두나무·가문비나무**), **남서방향** 임연부 |
| 치묘 열해 | 7~8월 · 약한 수종: 전나무·가문비·편백 / 강한 수종: 소나무·곰솔·측백 |
| 만상(晩霜) | **봄** 늦서리 · 약한 수종: 잎갈나무류·오리나무류·자작나무류 |
| 조상(早霜) | **늦가을** 이른서리 |
| 상륜 | 만상 때문에 한 해에 연륜이 **2개** 생기는 현상 |

## 2. 대기오염 피해

| 오염물질 | 증상 |
|---|---|
| SO₂ | 엽맥간 괴사, 잎 앞·뒷면 모두, 연반 2~4일 뒤 · 늦봄~초여름 가장 민감 |
| O₃ | 책상조직 손상 → **잎 앞면** |
| HF | 엽록괴사, 갈색 밴드 |
| PAN | **잎 뒷면 은회색** 광택 |

## 3. 산불 ★

| 항목 | 내용 |
|---|---|
| 종류 | 지중화 · **지표화**(가장 흔함, 4~7km/h) · **수관화**(V자형, 진화 곤란) · 수간화 |
| 발생 조건 | 상대습도 **50% 이하** 발생 쉬움, **25% 이하** 수관화 대부분 |
| 시기 | **3~4월**, 13~16시에 약 49% |
| 소화약제 | **MAP**(제1인산암모늄), DAP(제2인산암모늄) · 헬기 살포 시 물보다 약 2배 효과 |
| 내화수림대 | 폭 **30m** 내외 · 맞불은 최후 수단 |

| 내화력 강함 | 내화력 약함 |
|---|---|
| 은행나무, 잎갈나무, 분비나무, 가문비나무, 개비자나무, 아왜나무, 굴거리나무, 동백나무, 사철나무, 가시나무, 회양목, 피나무, 고로쇠, 참나무 | **소나무, 곰솔, 삼나무, 편백**, 녹나무, 구실잣밤나무, 아까시나무, 벚나무, 능수버들 |

## 4. 산림보호법 시행령 과태료 🆕 (1차 / 2차 / 3차)

| 위반 | 금액 |
|---|---|
| 신고 없이 숲가꾸기 벌채 | 100 / 300 / 500만원 |
| 허가 없이 입산통제구역 출입 | 10만원 |
| 다량 쓰레기 투기 | 50 / 70 / 100만원 |
| 나무병원이 처방전 없이 농약 사용 | 150 / 300 / 500만원 |

## 5. 병원체 분류 ★

| 병원 | 대표 병 |
|---|---|
| 균류(진핵) | 흰가루병, 그을음병, 청변병, 리지나뿌리썩음병, 밤나무줄기마름병, **잣나무털녹병**, 소나무혹병 |
| 세균(원핵) | 뿌리혹병, 불마름병, 세균성구멍병 |
| 파이토플라스마(세포벽 없음) | **대추나무·붉나무 빗자루병**, 뽕나무 오갈병 |
| 바이러스 | 모자이크병 |
| 선충 | **소나무재선충병** |
| 기생식물 | 겨우살이, 새삼 |

- 세균·바이러스는 각피를 직접 뚫지 못함
- 파이토플라스마·바이러스·재선충은 **매개충이나 접목 상처**로만 침입
- 외과적 치료는 바이러스·파이토플라스마에 효과 없음

## 6. 소나무재선충병 ★ 🆕 (방제지침 매년 개정)

| 항목 | 내용 |
|---|---|
| 기주 | 소나무·곰솔·잣나무 (리기다·테다는 피해 적음) · 1988년 일본에서 유입 |
| 매개충 | **솔수염하늘소, 북방수염하늘소** |
| 매개충 방제 | 우화기 **5~8월**, 티아클로프리드 10% 액상수화제 · 지상 1,000배액 / 항공 500배액 |
| 예방 나무주사 | **아바멕틴 1.8%**, 에마멕틴벤조에이트 2.15% |
| 훈증 | 1~2㎥로 쌓고 **메탐소디움** 처리 후 밀봉 |
| 진단 | 줄기 천공 후 1~2시간 뒤 수지가 안 나오면 감염 의심 |
| 반출금지구역 | 발생지역과 그로부터 **2km 이내** |
| 선단지 구분 | 감염목 반경 **2km** 기준 (점형·선형·광역) |
| 소구역모두베기 | 벌채지 외곽 **30m** 내외 |
| 정기예찰 | 매년 **4월** 기준 |

## 9. 기상피해 세부 (모듈 p.4–7) — 심화

| 피해 | 핵심 |
|---|---|
| 상렬 | 수액이 얼어 수간 외층이 수선 방향으로 갈라짐 · 단단하고 수선 발달한 **활엽수 거목** |
| 상주(서릿발) | **점토질** 토양에서 잘 생김 · 묘상 15cm 높이고 짚·낙엽 피복, 이른 봄 뿌리 밟기 |
| 한해 | 약함: 버드나무·포플러·오리나무·들메나무(습생) / 강함: 소나무·곰솔·리기다·자작·서어나무(건생) |
| 바람 | 주풍 **10~15m/s**, 폭풍 **29m/s 이상** · 편심생장: 침엽수 **상방**, 활엽수 **하방** · 천연림·혼효림이 내풍력 강함 |
| 눈 | 관설해(가늘고 긴 밀식 임목은 신설 20cm에도) · 설압해(급사면 뿌리뽑힘, 평탄지 줄기 부러짐) |
| 소화 | 직접소화(물·토사·MAP/DAP) vs **간접소화(방화선·맞불·내화수림대)** · 보호 모듈 내화수림대 수종: 참나무류·아왜나무·잣나무·밤나무·가시나무류·낙엽송·잎갈나무, 폭 30m 내외 |

## 6. 🛡️ 산림보호학 핵심 비교 정리표 (수험생 빈출)

### 1) 나무 질병의 3대 병원체 비교
| 병원체 종류 | 주요 특징 | 치료 및 약제 | 대표 질병 |
| :--- | :--- | :--- | :--- |
| **진균 (곰팡이)** | 산림 수병의 약 80% 차지. 포자로 번식 | **살균제** (보르도액, 다이센 등) | 잣나무 털녹병, 모잘록병, 그을음병 |
| **세균 (박테리아)** | 세포벽 있음. 비바람이나 전정 가위로 전파 | **항생제** (스트렙토마이신 등) | 뿌리혹병(근두암종병), 불마름병 |
| **파이토플라스마** | 세포벽 없음. 매미충 등 곤충이 매개 | **테트라사이클린계** 항생제 주사 | 대추나무 빗자루병, 오동나무 빗자루병 |

### 2) 산림 화재 4대 유형 비교
| 산불 형태 | 타는 부위 | 전파 속도 및 위험도 | 진화 난이도 |
| :--- | :--- | :--- | :--- |
| **지표화 (地表火)** | 낙엽, 잡초, 작은 관목 | 가장 흔하며 바람 따라 확산 | 일반 진화선 구축 가능 |
| **수관화 (樹冠火)** | 나무 꼭대기(가지·잎) | 불티 날림(비화) 동반, 가장 위험 | 직화 진화 불가, 방화선 필요 |
| **수간화 (樹幹火)** | 나무 줄기 자체 | 보통 고사목이나 동공 부위 | 벌목 또는 주수 소화 |
| **지중화 (地中火)** | 땅속 부식토, 이탄층 | 연기 없이 은밀히 타들어 감 | 진화 최난관 (파헤치고 주수) |
