# 📊 [03_암기요약표] 01. 과목별 핵심 수치 & 공식 한눈에 보기

시험장 들어가기 직전 10분 동안 반드시 확인해야 하는 필수 숫자와 공식 총정리표입니다.

---

## 1. 조림학 필수 수치 및 공식

| 항목 | 핵심 기준 수치 / 공식 | 시험 출제 포인트 |
| :--- | :--- | :--- |
| **식재 본수** | 1ha당 보통 **3,000본** (경제수종 기준) | $3,000\text{본} = 10,000\text{m}^2 \div (\text{간격 } 1.8\text{m} \times 1.8\text{m})$ |
| **순량률** | $\text{순량률} = \frac{\text{순수 종자량}}{\text{전체 종자량}} \times 100$ | 불순물(돌, 껍질)을 뺀 알짜배기 씨앗 비율 |
| **발아세** | 정해진 중간 날짜(보통 1/3 시점)까지의 발아율 | 발아 속도의 균일성과 힘을 나타냄 |
| **효율(실효종자율)** | $\text{발아율} \times \text{순량률} \div 100$ | 실제 싹이 틀 수 있는 최종 씨앗 능력 |
| **노천매장 기간** | 종자 파종 전 **1~3개월** 저온 습윤 보관 | 호두, 은행, 잣나무 등 두꺼운 껍질 휴면 타파 |

## 2. 산림보호학 필수 암기 수치

| 항목 | 핵심 기준 수치 | 주요 내용 |
| :--- | :--- | :--- |
| **소나무재선충** | 매개충 크기 **약 2~3cm**, 선충 **1mm 미만** | 솔수염하늘소 성충 1마리당 최대 수만 마리 재선충 보유 |
| **방제 거리** | 잣나무 털녹병 중간기주 제거 반경: **1~2km** | 송이풀, 까치밥나무 포자 비산 한계 거리 |
| **산불 위험 계절** | 봄철(**3~4월**), 가을철(**11월**) | 건조기, 이동성 고기압, 양간지풍 영향 |
| **농약 희석 배수** | 소요 약량 = $\frac{\text{살포액량}}{\text{희석배수}}$ | 예: 1,000배액 20L 만들 때 원제 20mL 필요 |

## 3. 임업경영학 필수 공식

| 항목 | 공식 | 의미 및 비고 |
| :--- | :--- | :--- |
| **가슴높이(흉고)** | 지상 **1.2m** (한국, 일본 기준) | 미국은 1.37m(4.5ft), 유럽 일부 1.3m |
| **형수 (Form Factor)** | $f = \frac{V}{g \cdot h}$ ($V$: 재적, $g$: 흉고단면적, $h$: 수고) | 보통 0.45 ~ 0.50 범위 |
| **프레슬러 생장률** | $P = \frac{V - v}{V + v} \times \frac{200}{n}$ | $V$: 현재 재적, $v$: $n$년 전 재적 |
| **정액법 감가상각** | $D = \frac{C - S}{N}$ | $C$: 취득원가, $S$: 잔존가치, $N$: 수명 |
| **Faustmann 공식** | $B_u = \frac{A_u + T_a(1+p)^{u-a} - c(1+p)^u}{(1+p)^u - 1} - \frac{v}{p}$ | 토지순수익 최대를 보장하는 산림기대가치 |

## 4. 임도 및 사방공학 설계 수치

| 항목 | 일반 기준 | 특수/예외 기준 | 비고 |
| :--- | :--- | :--- | :--- |
| **임도 유효너비** | **3.0m** | 길어깨 포함 3.6m 내외 | 대피소 폭: 5.0m 이상 |
| **최소 곡선반경** | 보통 **12~15m 이상** | 부득이한 경우 10m | 설계속도에 비례 |
| **종단 기울기** | **10% 이하** | 특수 지형 최대 13~15% | 눈·비 올 때 미끄럼 방지 |
| **횡단 배수 경사** | **3 ~ 5%** (비포장 기준) | 포장로는 1.5 ~ 2% | 도로 표면 빗물 배제 |
| **대피소 간격** | **300m 이내**마다 1개소 | 길이 15m 이상 | 트럭 교행 목적 |
| **사방댐 높이** | 보통 **3 ~ 5m** 내외 | 최대 8m 이하 | 계류 경사에 따라 결정 |
| **양단면평균법** | $V = \frac{A_1 + A_2}{2} \times L$ | 토공량(흙 절·성토량) 산출 공식 |  |
