## 1. 경영 원칙과 벌기령

- **최고 지도원칙**: 공공성 · 수익성 / 그 밖: 경제성(수익÷비용 최대, 수익성의 전제), 생산성, **보속성**
- **벌기령 종류**: 조림적(생리적) · 공예적 · 재적수확 최대(벌기평균생장량 최대) · 화폐수익 최대 · 산림순수익 최대 · **토지순수익 최대(= 토지기망가 최대, 이재적 벌기령, 이율 높으면 짧아짐)** · 수익률 최대
- 법정벌기령: 벌채령 = 벌기령 · **윤벌기**: 작업급을 한 번 다 베는 기간 · **회귀년**: 택벌구를 다시 택벌하기까지 기간

## 4. 산림평가 ★

**임업이율의 성격**: 대출이자 ✕ → **자본이자** / 현실이율 ✕ → **평정이율** / 실질이율 ✕ → **명목이율** / **장기이율**

**복리 공식** (P = 이율)

| 구분 | 공식 |
|---|---|
| 후가 | N = V(1+P)ⁿ |
| 전가 | V = N / (1+P)ⁿ |
| 무한연년이자 전가 | r / P |
| 무한정기이자 전가 | R / [(1+P)ⁿ − 1] |
| 유한연년이자 후가 | r[(1+P)ⁿ − 1] / P |

**임지평가 방법**

| 방식 | 방법 |
|---|---|
| 원가방식 | 원가법, 비용가법(투입비용 후가, 최저가) |
| 수익방식 | **기망가법**(일제림, 무한정기이자식), 수익환원법(택벌림, 무한연년이자식) |
| 비교방식 | 직접·간접(역산) |
| 절충방식 | 수익가·기망가·수확수익·주벌수익(Mantel) 비교절충 |

**임지기망가** Bu = [Au + ΣDa(1+P)^(u−a) − C(1+P)^u] / [(1+P)^u − 1] − v/P

| 인자 | 기망가 크기 | 최대값 도달 시점 |
|---|---|---|
| 주벌·간벌수익 ↑ | 커짐 | 간벌수익 클수록 **빨라짐** |
| 조림비 ↑ | 작아짐 | **늦어짐** |
| 관리비 ↑ | 작아짐 | **무관** |
| 이율 ↑ | 작아짐 | **빨라짐** |
| 지위 좋음 | – | 빨라짐 |
| 채취비 ↑ | – | 늦어짐 |

**임목평가 (영급별 적용)** ★

| 임령 | 방법 |
|---|---|
| 유령림 | 원가법(보통 15년 이내), **비용가법** (우량임지가 오히려 낮게 평가되는 경향) |
| 중령림 | **Glaser법**: Am = (Au − C) × m²/u² + C (이율 안 씀) |
| 벌기 미만 장령림 | **기망가법**(최고가, 기망가 최대 임령 = 경제적 벌기령), 수익환원법 |
| 벌기 이상 | 매매가법, **시장가역산법**: x = f × [a / (1 + m·p + r) − b] |

- 임목비용가 Hk = (B+V)[(1+P)^m − 1] + C(1+P)^m − ΣDa(1+P)^(m−a), V = v/P
- 시장가역산 기호: f 이용률(조재율), a 원목 단가, m 회수기간, p 월이율, r 기업이익률, b 단위 생산비

## 5. 감가상각과 원가

| 방법 | 공식 / 예제 |
|---|---|
| 정액법 | (취득 − 잔존) / 내용연수 · 예: (1,000만 − 100만)/60년 = 15만원 |
| 정률법 | 감가율 = 1 − (잔존/취득)^(1/n) |
| 연수합계법 | 10년이면 분모 55, 1년차 10/55 |
| 작업시간비례법 | 체인톱 (50만 − 5만)/1,500h = 300원/h → 800h면 **240,000원** |
| 생산량비례법 | 생산량 비례 |

- 원가: 직접·간접 / 변동·고정 / **매몰·기회** / 한계·증분 · 개별원가(주문생산) vs 종합원가(연속생산) · 실제원가 > 표준원가 = 불리한 차이

## 6. 임가경제 ★

| 지표 | 공식 |
|---|---|
| 임가소득 | 임업소득 + 농업소득 + 기타소득 |
| 임업소득 | 임업조수익 − 임업경영비 |
| 임업순수익 | 임업소득 − 가족임금추정액 |
| 임업의존도 | 임업소득 ÷ 임가소득 |

## 7. 손익분기와 투자분석 ★

- 공헌이익 = p − v · 공헌이익률 = (p − v)/p
- 손익분기 수량 q = FC/(p − v) · 매출액 S = FC/(1 − v/p) · 목표이익 R: q = (FC + R)/(p − v)
- 모듈 예제: p 5만, v 3만, FC 60만 → **30㎥ · 150만원** / 목표이익 200만 → **130㎥ · 650만원**

| 기법 | 판단 기준 |
|---|---|
| 회수기간법 | 시간가치 무시 · 예제 답 A사업 2.75년 |
| 투자이익률법 | |
| NPV | **> 0** 투자 · 절대치라 규모 다른 안 비교 어려움 |
| B/C | **> 1** 투자 |
| IRR | NPV = 0인 할인율, **> 시장이자율**이면 투자 |
| 감응도분석 | 가격, 생산량, 원자재, 사업기간 지연 |

## 10. 생장과 측정

- **CAI 최대** = 총생장곡선 변곡점 · **MAI 최대** = 원점에서 그은 접선의 접점, 이때 **CAI = MAI** (그 전 CAI > MAI, 그 뒤 CAI < MAI)
- 생장률: 단리 (V−v)/(n·v) · 복리 (V/v)^(1/n) − 1 · **Pressler** (V−v)/(V+v) × 200/n · **Schneider** K/(n·D), K는 직경 30cm 이하 550, 초과 500
- 재적식: **Smalian** (g₀+gₙ)/2 × L · Huber g_m × L · Newton (g₀ + 4g_m + gₙ)/6 × L
- 원목 검척: 지름 10mm 단위 버림, 말구지름은 수피 뺀 최소지름, 길이 0.1m 단위 버림, 재적 소수 3자리
- 원목 등급: 특용재급, 1·2·3등급, 원주재급, 원료재급
