# 조림 암기 요약표

> 기준: 2026 학습모듈 「조림」(V08.26). 쪽수는 모듈 하단 쪽번호. ★ = 숫자형 고빈도
> 「전공서적 보충」 표시는 모듈에 거의 없지만 직무소개 필요지식(수목생리·토양·종자)에 들어 있어 산림기사 교재로 보충할 부분

## 1. 산림 기능과 목표

| 항목 | 내용 |
|---|---|
| 6대 기능 | 목재생산림 · 수원함양림 · 산지재해방지림 · 자연환경보전림 · 산림휴양림 · 생활환경보전림 |
| 기능구분도 | **10년마다**, 축척 1/25,000 이상 |
| 목표생산재 ★ | 대경재 DBH **40cm 이상** / 중경재 20~40cm / 소경재 20cm 미만 |
| 산림식생기후대 | 온대북부 6~9℃ / 온대중부 9~12℃ / 온대남부 12~13℃ / 난대 13~14℃ (연평균기온) |

## 2. 식재 ★

| 항목 | 기준 |
|---|---|
| 소나무·해송·편백·참나무류 | ha당 **5,000본** (1.4m 간격) |
| 잣나무·낙엽송 | ha당 **3,000본** (1.8m 간격) |
| 용기묘 | ha당 3,000본 |
| 5본 군상식재 | 식재목 간 1.2m, 군간 4.1m |
| 2열 부분밀식 | 목간 1m, 군간 6.6m |
| 봄 식재 적기 보정 | 표고 100m↑마다 약 **5일 늦게**, 북사면은 남사면보다 약 5일 늦게 |

| 지역 | 봄 | 가을 |
|---|---|---|
| 난대 | 2월 하순~3월 하순 | 10월 하순~11월 중순 |
| 온대남부 | 3월 상순~4월 상순 | 10월 중순~11월 상순 |
| 온대중부 | 3월 중순~4월 중순 | 10월 상순~하순 |
| 온대북부 | 3월 하순~4월 하순 | 9월 하순~10월 중순 |

**활착률** ★: **80% 미만 → 보식**, **50% 미만 → 재조림** · 조사 표준지는 풀베기 면적의 2% 이상, 200㎡(반지름 8.0m), 1ha 미만은 100㎡(반지름 5.67m) · 활착률 = 생존본수 ÷ 조사본수 × 100

**파종조림**: 가을 10~11월 / 봄 중부 4월 상순·남부 3월 하순 · 복토는 종자 지름의 **2~3배** · 단점은 연 3회 이상 풀베기

## 3. 갱신

| 작업종 | 핵심 |
|---|---|
| 개벌 | 대면적·대상·군상 |
| 산벌 | **예비벌 → 하종벌 → 후벌** (전갱작업) |
| 모수작업 | 모수 ha당 **15~20본**, 1구역 5만㎡ 이내 |
| 택벌 | 회귀년마다 반복 |
| 왜림(움싹) | 생장휴지기(**11~2월**) 벌채, 그루터기 지상 **10cm 이내**, 절단면 남향으로 약간 경사 |
| 지면긁기 | 등고선 방향, 종자 떨어지기 전 |

**움싹갱신** ★: 참나무 Ⅱ~Ⅲ영급, 그루터기 ha당 **900본** 내외 · 3년 안에 움싹 ha당 **3,000본 미만이면 조림** · 본수조절 2~3년차, 1~2본 남김

**조림 의무 면제(법)** ★: 어린나무 ha당 **2만본** / 참나무 어린나무 **5천본** / 움싹 왕성한 참나무 그루터기 **900개**

## 4. 숲가꾸기 ★

| 작업 | 대상·시기 | 기준 |
|---|---|---|
| 풀베기 | 조림 당년~**5년차** | 연 1회면 5~7월, 2회면 2차 8월~9월 초순 · 조림목이 식생보다 1.5배 크거나 활착률 50% 미만이면 제외 · 줄베기 폭 90~100cm, 둘레베기 반경 50cm |
| 덩굴제거 | 피복도 **50%** 이상 | 직경 1cm 이상 칡 주두부 ha당 1,600본 · 약제 1ha당 800ℓ |
| 어린나무가꾸기 | 조림 후 **5~15년**, DBH 2~8cm | 조림성공지 50% 이상 생존 / 혼생지 26~49% / 천연활엽수림 25% 이하 · 치수림 5~11월, 유령림 연중 · 천연림은 상층 평균수고 8m까지 2회 |
| 가지치기 | 11월~이듬해 **5월 이전** | 지름 **5cm 이상 가지 자르지 않음** · 어린나무가꾸기 단계 수고의 50%, 솎아베기 단계 50~60% · 침엽수는 줄기와 평행, 활엽수는 지융부 보호 · 생활환경보전림 침엽수 최대 6m |
| 솎아베기 | 어린나무가꾸기 후 5년 ~ 최종수확 10년 전 | 정량·도태간벌 조건: 우세목 평균수고 **10m 이상 + 15년생 이상** · 강도 간벌도 본수 기준 **50% 초과 금지**, 기준본수 ±30% 조정 |

제거 순서: 고사·피해목 → 피압목 → 생장불량목 → 형질불량목 → 우량목 방해목

**도태간벌** ★ (쉐델린, 상층간벌): 미래목은 피압 안 된 우세목(폭목 제외) · 미래목 간 최소 **5m** · 활엽수 ha당 **200본**, 침엽수 200~400본 · 미래목만 가지치기 · 가슴높이에 폭 10cm **황색** 페인트 · 하층 보호목은 제거 안 함 · 본수표 적용 안 함

**열식간벌**: 2열 이상 남기고 1열 벌채, 잣나무·낙엽송 조림지에 예외적으로

**천연림보육**: 우량목 ha당 200본 내외 + 지위 '중' 이상 → 목표 대경재 · 미래목 부족하면 천연림개량

| 항목 | 기준 |

## 7. 전공서적 보충 (산림기사 조림학 범위)

- **종자 품질**: 순량률(%) = 순정종자 무게 ÷ 전체 무게 × 100 · 발아율 = 발아 종자 수 ÷ 시험 종자 수 × 100 · **효율 = 순량률 × 발아율 ÷ 100** · 발아세 = 일정 기간(발아 최성기) 내 발아율
- **휴면타파**: 노천매장(잣나무·벚나무 등 종피 단단하거나 배 미숙), 침수처리, 황산처리(아까시나무 등 경실), 지베렐린
- **내음성**: 음수 = 주목·전나무·가문비나무·서어나무·너도밤나무 / 양수 = 소나무·낙엽송·자작나무·포플러·버드나무
- **토양층위**: A₀(유기물층, L-F-H) → A(용탈층) → B(집적층) → C(모재층) · 산림조사 토성은 **B층** 촉감법
- **균근**: 외생균근(소나무과·참나무과) / 내생균근(VA균근, 대부분 활엽수·초본)
- **광보상점**: 광합성량 = 호흡량인 광도, 음수가 양수보다 낮음
