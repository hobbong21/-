## Ⅰ. 산림자원의 조성 및 관리에 관한 법률 (산림자원법)

### 정의
- **산림에서 제외**: 과수원, 차밭, 삽수·접수 채취원, 건물 담장 안, 논·밭두렁, 하천·제방·도랑·연못의 입목
- **산림에 포함**: 임도, 암석지, 소택지
- **임산물**: 조경수·분재수, 가지·꽃·열매·장작·톱밥, 대나무·초본·덩굴·이끼, 산림버섯·떼, 숯·수액(목초액 포함), 합판·집성재·목재펠릿
- 소유별: 국유림 · 공유림 · 사유림 / 임도: **간선 · 산불진화 · 작업**임도

### 계획·조사 주기 ★

| 대상 | 주기 | 비고 |
|---|---|---|
| 기능구분도 | 10년 | 1/25,000 이상 |
| **임상도** | **5년** | 1/25,000 이상, 필요하면 수시 |
| 산림조림계획 | 10년 | |
| 전국임도기본계획 | 10년 | 임도설치계획 **5년** |
| 산림생물다양성기본계획 | 5년 | |
| 산림복원기본계획 | 10년 | |
| 산림자원조사 | 매년 실시, **5년마다 공표** | 타인 토지 출입은 **3일 전** 통지 |
| 산림경영계획 | **10년** 단위 | 시장·군수·구청장 인가 |

### 산림경영계획
- 경영계획구: 공유림 / 사유림(일반 · 협업(2인 이상) · 기업경영림)
- 필수 기재: 조림, 숲가꾸기, 벌채·굴취, 임도·작업로, 소득사업
- **15ha 이하** 인가 산림 → 산림조합 등에 **대리경영 권장**, 사업비 우선 지원 ★

### 입목벌채 수반 산림사업 신고 ★
- 착수 **5일 전**까지 시장·군수·구청장에게
- 사업구역도 축척 1/6,000 ~ 1/1,200
- 독림가·임업후계자 직접 신고, 임도 설치 → 구역도·수량조사서 생략
- 산림조합이 구역도 작성·표시 → 현지확인 생략 가능

| 표시 | 색 |
|---|---|
| 경계 (30m 이내 간격) | **백색** |
| 솎아베기·골라베기 대상목 | **적색** |
| 모두베기·모수작업 존치목 | **황색** (존치목 벌채 시 황색 아래 적색) |
| DBH 20cm 이하 솎아베기 대상지 | 표시 생략 가능 |

### 벌채 허가·신고 구분 ★

| 구분 | 대상 |
|---|---|
| 허가 변경 중요사항 | 구역면적, 벌채·굴취 면적, 허가수량 **30% 이상** 변경 |
| 허가 금지지역 | 명승지·유적지 등 고시지역, 산사태 위험지역 (예외: 병해충·재해 피해지, 숲가꾸기) |
| **신고**로 가능 | 오동나무·현사시·이태리포플러·양버들·옻나무·황칠나무·미루나무 / DBH **20cm 이하** 솎아베기 / 표고용 연 **50㎥** 이내 / 지목 전·답·과수원 5천㎡ 이상 / 대나무 굴취 1천㎡ 이내 / 철도선로 10m 이내 굴취 |
| **허가·신고 없이** | 풀베기·가지치기·어린나무가꾸기 / 바이오매스용 신규 조림 후 5년 이내마다 벌채 / 건축물 외곽 **25m 이내** 산불예방 벌채(소유자 동의) / 국유림경영계획·휴양림·수목원·산지전용·토석채취 허가에 따른 벌채 |

### 종묘·사업자
- 종묘생산업 등록: **시장·군수·구청장** · 요건: 임업종묘기능사 또는 임업·녹지직 4년 + 종묘 1년 등
- 묘목생산 대행자: 등록 후 **2년** 이상, 포지 **5천㎡** 이상, 용기묘는 간이온실 · 3년 연속 지정량 90% 미달이면 제외
- **산림사업법인 등록: 시·도지사** · 등록 없이 가능: 국가·지자체, 산림소유자, **산림조합·중앙회**, 국유림영림단, 원목생산업자, 나무병원 · 영업정지 안 날부터 **30일** 이내 계약 해지 가능
- 산림사업 대행(조합·중앙회): 재해 예방·복구, 설계·감리 대상, 국가산림자원조사, 경영계획 작성, 휴양·도시숲·교육시설 · 숲가꾸기는 소유자 주소불명 시 **30일 이상 공고**로 동의 갈음
- 특수산림사업지구: **300ha** 이상, 자원조성 대상 50% 이상, 경영가능지역 70% 이상

### 산림경영지도원 (법 제31조) ★
- **산림청장**이 **중앙회장의 요청**으로 조합·중앙회에 배치, 경비 보조 가능
- 자격(시행령): 임산가공산업기사·산림기능사·임업종묘기능사·목재가공기능사·펄프제지기능사·조경기능사 이상 / 임업·조경 학과 졸업 / 농업계 특성화고 임업과 / 고졸 + 조합 임업기술 2년 / 조합 3년 종사
- 배치(시행규칙): 정원은 산림청장 고시, **중앙회장이 선발·배치** · 운영계획 매년 **12월 말**까지, 전년도 평가보고서 **2월 말**까지 산림청장에게

### 기타
- 🆕 선도 산림경영단지 선정요건: ① 산림 집단화 ② 입목축적·조림비율 등 산림 여건 ③ 임도·목재유통가공시설 등 경영기반
- 산림복원: 주체 국가·지자체, 시공 산림토목 법인·산림조합·중앙회, 자생식물·자연재료(주변 또는 유사 고도·기후대)
- **녹색자금**: 산림청장 운용, 재원 출연금·**복권수익금**·운용수익·기부금
- 융자 시 임야·입목 담보 가능, 미성숙 입목도 가격 평가해 담보

## Ⅱ. 임업 및 산촌 진흥촉진에 관한 법률 (임업진흥법)

### 사람 기준 ★

| 구분 | 요건 |
|---|---|
| **임업인** | 3ha 이상 경영 / 연 **90일** 이상 종사 / 임산물 연 판매 **120만원** 이상 / 산림조합원으로 임업 경영 — 중 하나 |
| **임업후계자** | **55세 미만** + 경영계획대로 경영 + (개인독림가 자녀 / 3ha 이상 소유 / 10ha 이상 국·공유림 대부·분수림 / 고시 기준 이상 종묘·버섯·산채 생산) |
| 모범독림가 | 300ha 이상 경영 또는 조림 100ha |
| 우수독림가 | 100ha 이상 또는 조림 50ha (유실수 20ha) |
| 자영독림가 | 5ha 이상 또는 유실수 3ha |
| 법인독림가 | 300ha 또는 조림 100ha (농업법인 10ha 또는 조림 5ha) |
| 겸업 / 전업 / 기업임업 | 3ha 또는 연 90일 / **50ha 또는 연 200일** / 500ha 법인 + 연 200일 |

### 그 밖 ★
- **특별관리임산물 = 산양삼** → 한국임업진흥원 생산적합성조사 → 산림청장에게 신고
- **임업인의 날: 11월 1일**
- 산촌: 산림면적 **70% 이상** + 인구밀도·경지비율이 전국 읍·면 평균 이하 · 산촌진흥지역은 **시·도지사** 지정 · 산촌진흥기본계획 **10년**
- 산지: 보전산지(임업용·공익용) + 준보전산지
- 대리경영 가능자: 임업인, 산림조합·중앙회, 시장·군수, 지방산림청장·국유림관리소장, 임업학과 있는 대학, 3종 등록 산림사업법인 등
- 영림단: **6~30명** · 기능인영림단 기능2급 이상 비율 6~10명 60%, 11~30명 50% · 기계화영림단 기계교육 이수자 30% 이상
- 임업진흥권역 지정: 산림청장(국유림, 100만㎡ 이상) / 시·도지사(3만~100만㎡) / 시장·군수·구청장(3만㎡ 미만) · 임업용산지에만, 산림비율 70% 이상
- 한국임업진흥원: 산양삼 품질관리, 산림탄소상쇄, 산림경영인증, 임업통계, 임상도 제작

## Ⅲ. 산림조합법

### 원칙
- 목적(제1조): 산림소유자·임업인의 자주적 협동조직 → 지속가능한 산림경영, 산림생산력 증진, 구성원 지위 향상
- 조합 = **지역조합**(시·군·구) + **전문조합**(품목·업종) · 같은 구역에 같은 종류 둘 이상 설립 불가
- 최대봉사(영리·투기 금지, 제5조) · 중앙회는 회원과 경합 사업 금지(제6조) · 공직선거 관여 금지(제7조) · 조세 외 부과금 면제(제8조)

### 설립 ★
- 발기인 **30인** 이상 → 창립총회 → **시·도지사 인가** (60일 안 통지, 안 하면 인가 간주)
- 인가기준: 지역조합 조합원 **1천인** 이상(특별·광역시·섬 300인) + 출자금 **1억원**(섬 1천만원) / 전문조합 **200인** + 1억원
- **설립등기로 성립**, 출자 납입 후 **2주** 안 등기

### 조합원 ★
- 지역조합원: 구역 안 주소·산림이 있는 산림소유자 또는 주소·사업장 있는 임업인 · 두 지역조합 동시 가입 불가
- 최소 산림면적 300~1,000㎡ (정관)
- 책임은 출자액 한도 · 출자금은 질권·상계 불가 · **의결권은 출자액 무관 평등** · 선거권은 임기만료일 전 **180일**까지 가입자 · 대리인은 1명만 대리
- 당연탈퇴: 자격 상실, 사망, 파산, 피성년후견 · 제명: 1년 이상 사업 미이용, 의무 불이행 (총회 10일 전 통지) · 지분환급청구권 **2년** 소멸

### 총회·임원 ★★ (가장 많이 나올 부분)

| 항목 | 기준 |
|---|---|
| 일반 의결 | 과반수 출석 + 출석 과반수 찬성 |
| 특별 의결 (정관변경·해산·분할·제명) | 출석 **2/3** 이상 찬성 |
| 조합원투표 | 해산·분할: 과반수 투표 + 2/3 찬성 / 합병: 과반수 투표 + 과반수 찬성 |
| 소집청구 | 조합원 **300인 또는 10%** 이상 → 조합장 **2주** 안 소집, 안 하면 감사 **5일** 안 |
| 소집통지 | **7일 전** |
| 대의원 임기 | 2년 |
| 임원 | 조합장 포함 이사 **7~15명** + 감사 **2명** · 이사의 1/2 이상 조합원 · 상임 2명 이내 |
| 조합장 상임 여부 | 자산 1천억 미만 상임, 2,500억 이상 비상임 |
| **임기** | 조합장·조합원 이사 **4년** / 상임이사·비조합원 이사 2년 / **감사 3년** |
| **조합장 연임** | **두 번까지** |
| 해임 | 조합원 1/5 동의 → 과반수 출석 + 2/3 찬성 |
| 의결 취소 청구 | **1개월** 안, 조합원 300인 또는 5% 동의 → 시·도지사 |

### 사업·회계
- 사업(제46조): 교육·지원, 경제, 신용, 공제, 산림사업(조림·숲가꾸기·임도·사방·경영계획)
- **수익분배계약(제50조) → 산주가 조합에 지상권 설정한 것으로 봄** ★
- 동일 법인 출자한도 자기자본의 **20%**
- 법정적립금: 자기자본 **3배**까지 잉여금의 **10%** 이상 · 교육지원사업비 잉여금 **20%** 이상 이월
- 손실보전 순서: 미처분이월금 → 임의적립금 → 법정적립금 → 자본적립금 → 회전출자금
- 배당 순서: 이용실적 → 출자 → 준조합원 이용실적
- 임업인 범위 확대(시행령 제2조): 종묘생산업자, 포지 300㎡, 대추·호두 1천㎡, 밤 5천㎡ 이상

### 중앙회 ★

| 항목 | 기준 |
|---|---|
| 목적(제87조) | 회원의 공동이익 증진과 건전한 발전 |
| 구역·회원 | 전국 · 지역조합·전문조합 |
| 설립(제93조) | **50개 이상 조합** 발기 |
| 가입 승낙 | **60일** 안 |
| 대의원 | 회원의 1/3 범위, 임기 2년 |
| 임원 | 회장·사업대표이사 포함 이사 **18명 이내** + 감사위원 **3명** (사업대표이사·감사위원장 상임) |
