# 🌲 [02_종합보고서] 01. 조림학 핵심 개념 및 쉬운 용어 사전

조림학(造林學)은 한마디로 **"인간에게 유익한 건강하고 울창한 숲을 만들고 가꾸는 학문"**입니다. 씨앗을 골라 묘목을 키우고, 산에 심어 큰 나무로 자라게 하는 전 과정을 다룹니다.

---

## 📖 1. 알기 쉬운 조림학 전문 용어 사전 (용어 번역기)

어려운 한자어와 일본식 용어를 일상 언어로 시원하게 풀어드립니다.

| 어려운 전문 용어 | 쉬운 우리말 풀이 | 비유 및 이해 꿀팁 |
| :--- | :--- | :--- |
| **적지적수 (適地適樹)** | **알맞은 땅에 알맞은 나무 심기** | 사람마다 맞는 옷이 있듯, 토양·기후·햇빛 조건에 꼭 맞는 나무를 심어야 잘 자랍니다. |
| **개벌작업 (皆伐作業)** | **모두베기 (싹쓸이 베기)** | 특정 구역의 나무를 남김없이 싹 베어내고 햇빛을 좋아하는 새 나무를 한꺼번에 심는 방식. |
| **택벌작업 (擇伐作業)** | **골라베기 (선택 베기)** | 숲에서 다 자란 나무나 병든 나무만 쏙쏙 골라 베어내어, 숲의 겉모습(울창함)을 항상 유지하는 방식. |
| **간벌 (間伐)** | **솎아베기** | 콩나물시루처럼 나무가 너무 빽빽하면 서로 햇빛 경쟁을 하느라 마릅니다. 우량한 나무를 위해 중간 나무를 솎아내는 작업. |
| **제벌 (除伐)** | **방해나무 베기 (잡목제거)** | 우리가 키우려는 나무의 성장을 방해하는 주변의 쓸모없는 잡목이나 덩굴을 잘라주는 작업. |
| **왜림 (矮林)** | **그루터기 싹 숲 (키 작은 숲)** | 나무를 밑동까지 베어낸 후, 그루터기에서 다시 돋아난 싹(맹아)을 키우는 숲. 땔감이나 버섯 표고목용(참나무 등)으로 씁니다. |
| **교림 (喬林)** | **씨앗으로 자란 큰 나무 숲** | 씨앗(종자)이 싹터서 곧고 높게 자란 숲. 우리가 흔히 보는 목재용 전나무·소나무 숲입니다. |
| **모수작업 (母樹作業)** | **엄마나무 남겨두기** | 숲의 나무를 대부분 베어내되, 좋은 씨앗을 널리 퍼뜨려줄 건강한 '엄마나무'를 1ha당 15~30그루 정도 남겨두는 방식. |
| **음수 (陰樹) vs 양수 (陽樹)** | **그늘 좋아하는 나무 vs 햇빛 좋아하는 나무** | 음수(주목, 잣나무 등)는 어릴 때 그늘에서도 잘 견디고, 양수(소나무, 자작나무, 낙엽송)는 햇빛이 쨍쨍해야 잘 자랍니다. |
| **가식 (假植)** | **임시 심어두기** | 묘목을 산에 정식으로 심기 전까지 뿌리가 마르지 않도록 땅을 파서 비스듬히 묻어두는 임시 보관법. |

## 🧠 2. 조림학 핵심 4대 테마 요약

### 테마 1: 종자(씨앗)와 발아
* **종자의 휴면 타파:** 씨앗이 겨울을 지나 봄에 싹을 틔우게 하려면 인위적으로 촉촉하고 시원한 모래 속에 묻어두는 **노천매장법(露天埋藏法)**을 주로 씁니다 (잣나무, 은행나무, 호두나무 등).
* **종자 품질 공식:**
  $$\text{순량률(\%)} = \frac{\text{순수한 종자 무게}}{\text{전체 종자 무게}} \times 100$$
  $$\text{효율(실효종자율, \%)} = \text{순량률(\%)} \times \text{발아율(\%)} \div 100$$

### 테마 2: 묘목(어린나무) 키우기
* **묘목 연령 표기법 (시험 단골):**
  * `1-0묘`: 파종상에서 옮겨심지 않고 1년 자란 묘목
  * `1-1묘`: 파종상에서 1년 자란 후, 다른 밭으로 옮겨 심어 1년 더 키운 2년생 묘목
  * `2-1-1묘`: 총 4년생 묘목 (2년 파종상 + 1년 판광 + 1년 판광)

### 테마 3: 숲을 만드는 방법 (인공조림 vs 천연갱신)
* **인공조림:** 사람이 직접 씨를 뿌리거나 묘목을 심어 숲을 조성 (식재 간격: 보통 1ha당 3,000본 기준).
* **천연갱신:** 자연적으로 떨어진 씨앗이나 그루터기 싹을 이용해 자연의 힘으로 숲을 복원.

### 테마 4: 숲가꾸기 (육림) 사이클
1. **풀베기(조림 후 1~3년):** 어린 묘목이 잡초에 묻히지 않도록 여름철(6~8월)에 실시.
2. **덩굴제거:** 칡, 찔레, 다래덩굴이 묘목을 감고 올라가지 않도록 제거.
3. **어린나무가꾸기(제벌):** 조림 후 5~10년, 목표 수종 외 잡목 제거.
4. **솎아베기(간벌):** 조림 후 15~20년 이후, 우량한 목재 생산을 위해 밀도 조절.

## 🎯 산림기사 기출 출제 포인트

> **Q. 양수(햇빛 나무)와 음수(그늘 나무)의 특징 비교 문제는 매회 출제됩니다.**
> * **극양수:** 자작나무, 낙엽송, 오시리나무, 포플러 (햇빛 없으면 바로 고사)
> * **양수:** 소나무, 상수리나무
> * **중용수:** 참나무류, 물푸레나무
> * **음수:** 잣나무, 단풍나무, 편백, 삼나무
> * **극음수:** 주목, 회송, 나도밤나무 (깊은 숲 그늘에서도 생존 가능)
