## 모의고사.html 쓰는 법

`05_모의고사/모의고사.html`을 더블클릭하면 브라우저에서 열립니다. 인터넷 연결이 필요 없습니다.

- **실전 모의고사**: 필수 4과목 + 선택 1과목, 과목당 20문항(50문항 중 무작위 또는 기본 1~20번), 150분 타이머 → 과목별 점수, **40% 과락**, **60% 평균** 판정, 해설
- **과목별 연습**: 과목·파트를 골라 한 문제씩 풀고 바로 해설 확인
- **오답노트**: 틀린 문제가 자동 저장되고, 다시 맞히면 빠집니다 (이 브라우저에만 저장)

문제 md 파일을 고치면 `python3 tools/build_quiz.py`로 html을 다시 만드세요.

## 이번 개선에서 바뀐 점

- **산림기사 시험범위 100% 연계 및 기출 반영:**
  * 조림학, 산림보호학, 임업경영학, 임도공학, 사방공학 핵심 기출 30제 및 실전 모의고사 20제 추가
  * 산림경영지도원 vs 산림기사 출제경향 분석 노트 탑재
- **어려운 전문 임업 용어 '쉬운 일상어 풀이(용어사전)' 추가:**
  * 한자어·일본식 표기(개벌, 간벌, 왜림, 적지적수, 법정림, 형수 등)를 직관적인 우리말로 풀이
- **시험 직전 암기 지원:**
  * 과목별 필수 계산 공식·수치 총정리표 및 헷갈리는 개념 1:1 비교표 신설
- 예상문제 120 → **300문항**: 모듈 미출제 단원 심화 120문항, 참고자료·전공서적 60문항 추가
- **산림경영·사방 공식을 학습모듈 PDF 원본 화면과 대조해 확인**하고 기호를 모듈 표기로 맞춤 (Hundeshagen법은 법정벌채량 En 사용으로 수정)
- 해설의 모듈 쪽수를 인쇄 쪽번호 기준으로 재확인 (법규 쪽수 1쪽씩 밀린 것 수정)
- 모듈 안에서 출처마다 다른 숫자·명칭(모두베기 면적, 내화수림대 폭, 기능 명칭, 곡선 정의)을 별도 정리
- 실전 모의고사 페이지(타이머·채점·과락 판정·오답노트) 추가
