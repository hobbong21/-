## 예상문제 구성 (총 300문항)

| 파트 | 번호 | 출제 범위 |
|---|---|---|
| Part 1 기본 | 1~20 | 학습모듈 핵심 숫자·기준 |
| Part 2 심화 | 21~40 | 1차에서 다루지 않은 모듈 단원 (기능별 산림, 안전사고, 해충 각론, 경영계획 절차, 임목수확, 임도 용어, 사방 연혁, 원목 규격 고시 등) + 2026 개정 부분 |
| Part 3 참고자료 | 41~50 | 각 모듈 '참고자료 목록'과 직무소개 '필요지식'의 전공서적 범위 (산림기사·임산가공기사 수준) |

모든 문항은 **직접 만든 예상문제이며 기출이 아닙니다.** 해설마다 학습모듈 쪽수(하단 인쇄 쪽번호)나 참고 분야를 적었습니다.

## 모의고사.html 쓰는 법

`05_모의고사/모의고사.html`을 더블클릭하면 브라우저에서 열립니다. 인터넷 연결이 필요 없습니다.

- **실전 모의고사**: 필수 4과목 + 선택 1과목, 과목당 20문항(50문항 중 무작위 또는 기본 1~20번), 150분 타이머 → 과목별 점수, **40% 과락**, **60% 평균** 판정, 해설
- **과목별 연습**: 과목·파트를 골라 한 문제씩 풀고 바로 해설 확인
- **오답노트**: 틀린 문제가 자동 저장되고, 다시 맞히면 빠집니다 (이 브라우저에만 저장)

문제 md 파일을 고치면 `python3 tools/build_quiz.py`로 html을 다시 만드세요.
