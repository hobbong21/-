## 모의고사.html 쓰는 법

`05_모의고사/모의고사.html`을 더블클릭하면 브라우저에서 열립니다. 인터넷 연결이 필요 없습니다.

- **실전 모의고사**: 필수 4과목 + 선택 1과목, 과목당 20문항(총 480문항 중 무작위 100문항 추첨), 150분 타이머 → 과목별 점수, **40% 과락**, **60% 평균** 판정, 해설
- **과목별 연습**: 과목·파트를 골라 한 문제씩 풀고 바로 해설 확인 (Part 1 기본 / Part 2 심화 / Part 3 참고자료 / **Part 4 산림기사 기출·실무**)
- **오답노트**: 틀린 문제가 자동 저장되고, 다시 맞히면 빠집니다 (이 브라우저에만 저장)

문제 md 파일을 고치면 `python tools/build_quiz.py`로 html을 다시 만드세요.

## 시험감독관 시각의 최종 점검 및 개선 내역

1. **시험감독관 심층 점검서 신설 (`02_종합보고서/05`):**
   * 출제위원이 밝히는 과목별 함정 선지(Trap Points) 집중 해부, 단위 환산 체크리스트, 150분 타임라인별 최적 OMR 마킹 전략 수록
2. **암기요약표 01, 02 중복 완전 해소 (`03_암기요약표`):**
   * 과목별 핵심 수치와 비교표를 각 과목 본문(`01. 조림.md`, `02. 산림보호.md`)으로 완벽 통합하고 중복 번호 파일 정리
3. **학습모듈 및 공고 폴더 구조 편리화 (`01_공식자료`):**
   * 특수문자 대괄호 폴더를 없애고 `01_공고_및_직무소개`, `02_학습모듈_교재_PDF`로 직관적 분류 및 안내 README 추가
4. **모의고사 및 문제 풀 광범위 확대 (총 480문항):**
   * 과목별 80문항씩 총 480문항으로 풀을 대폭 넓히고, 1문 1답 순차 풀이와 실전 모의고사 100제 정밀 제공
