## 모의고사.html 쓰는 법

`05_모의고사/모의고사.html`을 더블클릭하면 브라우저에서 열립니다. 인터넷 연결이 필요 없습니다.

- **실전 모의고사**: 필수 4과목 + 선택 1과목, 과목당 20문항(70문항 중 무작위 또는 기본 1~20번), 150분 타이머 → 과목별 점수, **40% 과락**, **60% 평균** 판정, 해설
- **과목별 연습**: 과목·파트를 골라 한 문제씩 풀고 바로 해설 확인 (Part 1 기본 / Part 2 심화 / Part 3 참고자료 / **Part 4 산림기사 기출**)
- **오답노트**: 틀린 문제가 자동 저장되고, 다시 맞히면 빠집니다 (이 브라우저에만 저장)

문제 md 파일을 고치면 `python tools/build_quiz.py`로 html을 다시 만드세요.

## 이번 개선에서 바뀐 점

- **산림기사 시험범위 내용 풍부화 통합:**
  * 산림기사 문제를 별도 파일로 분리하지 않고, **산림경영지도원 시험범위와 겹치는 6개 과목 본문에 직접 통합(Part 4, 과목당 20문항 추가)**하여 총 420문항으로 대폭 확대
- **1문 1답 순차 풀이 구조 전면 개편:**
  * 기존의 '문제 목록 ➔ 하단 정답표' 분리 구조를 없애고, **모든 문제 바로 아래에 `정답 ➔ 상세 해설 ➔ 출제 근거`가 순서대로 배치**되는 순차적 구조로 개편하여 학습 즉시성 극대화
- **어려운 전문 임업 용어 '쉬운 일상어 풀이(용어사전)' 추가:**
  * 한자어·일본식 표기(개벌, 간벌, 왜림, 적지적수, 법정림, 형수 등)를 직관적인 우리말로 풀이
- **CBT 웹앱 420문항 완벽 연동:**
  * 개편된 순차 마크다운 구조를 `tools/build_quiz.py`가 완벽 파싱하여 `모의고사.html`에 420문항 실전 반영
